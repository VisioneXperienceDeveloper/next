# 라이선스·콘텐츠 권리 기록

- 제공 브랜드: VXDeveloper. Bundle ID: com.visionexperiencedeveloper.next.
- 앱 소스: 이 작업공간에서 Next용으로 작성. 외부 SDK·패키지 의존성 없음.
- 아이콘: imagegen으로 이 제품용 생성. 원본과 1024px 납품본 보관. 이전 아이콘도 삭제하지 않고 별도 보관.
- 화면 이미지: 실제 Next 시뮬레이터 실행 캡처. 테스트에서 직접 입력한 가상의 개발자 진로 예문. 실제 개인 기록 사용 없음.
- 앱 내부 SF Symbols/시스템 폰트: Apple 플랫폼의 네이티브 UI로 사용. 시스템 심볼을 앱 아이콘 원본으로 사용하지 않음.
- 이미지 생성 프롬프트·제작 내역: assets/README.md 참조. 공개 전 이름과 기호의 상표 충돌 검토는 개발자 책임으로 남아 있음.

## 이용약관

별도 계정·서버·결제 서비스 약관이 필요하지 않은 현재 구성에서는 Apple 기본 EULA를 사용하는 방향이 가장 작습니다. 별도 사용자 계약을 새로 발명하지 않았습니다. App Store Connect에서 custom EULA를 설정하지 않으면 기본 계약이 적용되는지 확인하고 진행합니다.

개인정보처리방침은 EULA와 별도로 공개합니다. 개발자 사업자 정보, 세무·은행·계약 정보는 App Store Connect 계정에서 직접 관리하며 이 저장소에 비밀키나 신분 서류를 넣지 않습니다.
