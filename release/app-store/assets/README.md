2026-09-11 소유자가 확정한 아이콘은 흰 배경에 검은 곡선 화살표와 두 개의 두꺼운 원판입니다. 그림자·광택 없이 흰색 경계선으로 원판의 두께를 표현했습니다. [선택 시안](../icon-concepts/2026-09-10-black-white/Next-Icon-AB-2D-thick-discs.png)은 built-in imagegen으로 만들었으며, [생성 프롬프트](../icon-concepts/2026-09-10-black-white/prompt-AB-2D-thick-discs.json)를 보관합니다. 원본 1254px을 sips로 1024px으로 변환했습니다. 알파와 바깥 모서리 마스크가 없고 기본·다크·틴트 슬롯 모두 같은 흑백 디자인입니다. 이전 빌드 2 아이콘은 previous/build2-green-icons에 보관합니다.

배너 문구: Next / One step toward your vision. / VXDeveloper. 실제 앱 UI를 모방한 이미지가 아니며 공개·다운로드 가능하다는 배지를 넣지 않았습니다. 이미지들은 생성 자산이며, 스토어 UI 캡처와 분리합니다.

AppIcon에 연결된 새 파일은 Next-v1 계열입니다. 생성 원본과 이전 아이콘은 런타임 자산이 아니라 이 폴더에 보관합니다. 이름·기호의 상표 충돌 확인은 출시 담당자가 최종 수행합니다.
