아이콘은 imagegen으로 생성한 따뜻한 아이보리/숲색의 앞으로 움직이는 기호입니다. 원본 1254px을 Apple 아이콘 형식에 맞게 sips로 1024px으로 변환했습니다. 알파 없음, 바깥 모서리 마스크 없음. iOS가 기기에서 마스크를 적용합니다. 다크·틴트는 원본을 참조한 색상 변형입니다.

배너 문구: Next / One step toward your vision. / VXDeveloper. 실제 앱 UI를 모방한 이미지가 아니며 공개·다운로드 가능하다는 배지를 넣지 않았습니다. 이미지들은 생성 자산이며, 스토어 UI 캡처와 분리합니다.

AppIcon에 연결된 새 파일은 Next-v1 계열입니다. 생성 원본과 이전 아이콘은 런타임 자산이 아니라 이 폴더에 보관합니다. 이름·기호의 상표 충돌 확인은 출시 담당자가 최종 수행합니다.
